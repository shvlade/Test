# Нейронные сети и Python-практика

> Учебные блокноты по нейронным сетям, анализу Titanic и основам Python: NumPy, Pandas, TensorFlow и визуализация.

**Стек:** Python · Jupyter · NumPy · Pandas · Matplotlib · TensorFlow

## Содержание

- `Нейронные_сети.ipynb` — перцептрон, сети Элмана и Хопфилда, классификация текстов, регрессия, LSTM и GRU.
- Блокноты с упражнениями по Pandas и анализу Titanic.
- Отдельные `.py` с базовыми задачами Python.

Основной материал для просмотра — блокнот с нейронными сетями. Он содержит эксперименты и обучающие примеры; единая оценка качества моделей для проекта не заявляется.

## Работа с блокнотами

Откройте нужный `.ipynb` в JupyterLab или Google Colab и выполняйте ячейки по порядку. Зависимости: NumPy, Pandas, Matplotlib, scikit-learn и TensorFlow; отдельные ячейки загружают внешние наборы данных.

Для локального просмотра: `python -m pip install jupyterlab`, затем `jupyter lab`. Некоторые `.py` используют синтаксис f-строк Python 3.12+, поэтому Python 3.11 не подходит для всех файлов.
